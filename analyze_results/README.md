# 분석 결과 (Analysis Results)

이 폴더에는 Needle In Haystack 테스트의 분석 결과가 저장됩니다.

## 📁 생성된 파일

### 1. `heatmap.png`
- **설명**: 컨텍스트 길이(X축)와 문서 깊이(Y축)에 따른 모델 성능을 시각화한 히트맵
- **색상**: 빨강(낮은 점수) → 노랑(중간 점수) → 초록(높은 점수)
- **용도**: 모델이 어떤 조건에서 잘 작동하고 어디서 어려움을 겪는지 한눈에 파악

### 2. `summary.json`
- **설명**: 전체 테스트 결과의 통계적 요약을 JSON 형식으로 저장
- **포함 내용**:
  - 전체 통계 (평균, 중앙값, 최고/최저 점수, 표준편차)
  - 컨텍스트 길이별 평균 점수
  - 문서 깊이별 평균 점수
  - 점수 분포
  - 최고/최저 성능 테스트 상세 정보
  - 성능 통계 (테스트 시간)

### 3. `analysis_report.txt`
- **설명**: 사람이 읽기 쉬운 텍스트 형식의 분석 리포트
- **용도**: 빠른 결과 확인 및 리포트 작성

## 📊 분석 예시

### Gemma-3-12b-it 모델 분석 결과 요약

- **총 테스트**: 84개
- **평균 점수**: 9.64/10
- **주요 발견**:
  - 32,000 토큰까지는 완벽한 성능 (10/10)
  - 70,000 토큰에서 약간의 성능 저하 (9/10)
  - 100,000 토큰에서 눈에 띄는 성능 저하 (6.71/10)
  - 문서의 시작(1%)과 끝(99%) 부분에서 가장 좋은 성능
  - 중간 부분(25%, 50%, 75%)에서 약간의 성능 저하

## 🔄 재분석 방법

분석 결과를 다시 생성하려면:

```bash
# 기본 디렉토리 (results_kor) 분석
python tools/analyze_results.py

# 특정 디렉토리 분석
python tools/analyze_results.py gemma3_results

# 다른 디렉토리 분석
python tools/analyze_results.py your_results_folder
```

## 📈 히트맵 해석 가이드

히트맵에서 확인할 수 있는 패턴:

1. **수평 줄무늬**: 특정 문서 깊이에서 모든 컨텍스트 길이에 걸쳐 성능이 일관되게 좋거나 나쁨
2. **수직 줄무늬**: 특정 컨텍스트 길이에서 모든 깊이에 걸쳐 성능이 일관되게 좋거나 나쁨
3. **대각선 패턴**: 컨텍스트 길이와 깊이의 조합에 따른 성능 변화
4. **어두운 영역**: 모델이 어려움을 겪는 조건 (추가 최적화 필요)
5. **밝은 영역**: 모델이 잘 작동하는 조건

## 💡 활용 방법

1. **모델 비교**: 여러 모델의 결과를 분석하여 성능 비교
2. **최적화 가이드**: 성능이 낮은 영역을 파악하여 모델 개선 방향 설정
3. **컨텍스트 윈도우 결정**: 실제 사용 시 적절한 컨텍스트 길이 선택
4. **리포트 작성**: 생성된 그래프와 통계를 활용하여 프레젠테이션 자료 작성
